# 五维史料雷达与《通鉴考异》长编技能

## 1. 五维史料雷达评估体系
1. **制度异文敏感度 (`institution`)**：识别清代官制、职官、公文程式在西文转译中的异文（如理藩院、笔帖式、奏折朱批）。
2. **隐蔽史料盲区度 (`blindspots`)**：发掘官修《实录》《会典》常隐去的底层通事、胥吏、关差耗银、行商暗号等微观细节。
3. **概念置换偏移度 (`conceptual`)**：以中国史学主体立场审视威斯特伐利亚主权话语对清代“藩服/朝贡/柔远”概念的强行套用与东方主义偏差。
4. **满汉洋母本冲突度 (`conflict`)**：比对清代满文底档、汉文刻本与西方未刊手稿之间的记载抵牾。
5. **前沿课题开拓潜力 (`frontier`)**：评估该档案转化为国家社科基金课题或高水平学术论文的突破空间，并输出具体研究假说与推荐互证传世文献。

## 2. 司马光体《通鉴考异》长编格式
- **【长编正文】**：综合多版本史料按时间与逻辑顺序熔铸叙事。
- **【考异】**：逐条列出中文母本、未刊手稿打字层、手写删改层与已刊本之异同，明辨删削动机与概念位移。
